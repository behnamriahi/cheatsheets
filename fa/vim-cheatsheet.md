# Vim Cheatsheet

## حالت‌ها (Modes)
```
ESC         # حالت عادی (Normal)
i           # حالت درج (قبل از نشانگر)
a           # حالت درج (بعد از نشانگر)
I           # درج در ابتدای خط
A           # درج در انتهای خط
o           # باز کردن خط جدید پایین
O           # باز کردن خط جدید بالا
v           # حالت انتخاب (کاراکتر)
V           # حالت انتخاب (خط)
Ctrl+v      # حالت انتخاب بلوکی
R           # حالت جایگزینی
:           # حالت دستوری
```

## ناوبری پایه
```
h           # حرکت به چپ
j           # حرکت به پایین
k           # حرکت به بالا

w           # کلمه بعدی
b           # کلمه قبلی
e           # پایان کلمه

{n}G        # برو به خط n
{n}gg       # برو به خط n
Ctrl+f      # صفحه بعد
Ctrl+b      # صفحه قبل
Ctrl+d      # نیم صفحه پایین
Ctrl+u      # نیم صفحه بالا
%           # پرش به براکت متناظر
```

## جستجو و جایگزینی
```
/{pattern}  # جستجو به جلو
?{pattern}  # جستجو به عقب
n           # تطابق بعدی
N           # تطابق قبلی
*           # جستجوی کلمه زیر مکان‌نما (به جلو)
#           # جستجوی کلمه زیر مکان‌نما (به عقب)
:%s/old/new/g       # جایگزینی تمام موارد در فایل
:%s/old/new/gc      # جایگزینی همه با تأیید
:s/old/new/g        # جایگزینی در خط جاری
:'<,'>s/old/new/g   # جایگزینی در انتخاب بصری
:noh        # حذف هایلایت جستجو
```

## حالت دستوری
```
:!{command} # اجرای دستور شل
:r !{command} # خواندن خروجی دستور در فایل
:w !sudo tee % # ذخیره فایل با sudo
:cd {path}  # تغییر پوشه
:pwd        # نمایش پوشه جاری
:set number # نمایش شماره خطوط
:set nonumber # مخفی کردن شماره خطوط
:set relativenumber # نمایش شماره خطوط نسبی
:set paste  # حالت چسباندن
:set nopaste # حالت عادی
:syntax on  # فعال‌سازی هایلایت سینتکس
:syntax off # غیرفعال‌سازی هایلایت سینتکس
:colorscheme {name} # تغییر طرح رنگ
```

## جستجو و جایگزینی پیشرفته
```
:%s/foo/bar/g       # جایگزینی تمام foo با bar در فایل
:%s/foo/bar/gc      # جایگزینی با تأیید
:'<,'>s/foo/bar/g   # جایگزینی در انتخاب بصری
:5,12s/foo/bar/g    # جایگزینی در خطوط 5-12
:.,$s/foo/bar/g     # جایگزینی از خط جاری تا انتها
:.,+5s/foo/bar/g    # جایگزینی در خط جاری و 5 خط بعد
:g/pattern/d        # حذف تمام خطوط منطبق با الگو
:v/pattern/d        # حذف تمام خطوط که با الگو منطبق نیستند
:g/pattern/s/foo/bar/g # جایگزینی در خطوط منطبق با الگو
```

## تنظیمات مفید (.vimrc)
```vim
set number              " نمایش شماره خطوط
set relativenumber      " نمایش شماره خطوط نسبی
set tabstop=4           " عرض Tab
set shiftwidth=4        " عرض دندانه‌گذاری
set expandtab           " استفاده از فضا به جای tab
set autoindent          " دندانه‌گذاری خودکار
set smartindent         # دندانه‌گذاری هوشمند
set hlsearch            " هایلایت جستجو
set incsearch           " جستجوی تدریجی
set ignorecase          " نادیده گرفتن حروف بزرگ/کوچک در جستجو
set smartcase           " حساس به حروف اگر حرف بزرگ استفاده شود
set mouse=a             " فعال‌سازی ماوس
set clipboard=unnamedplus " استفاده از کلیپ‌برد سیستم
syntax on               " فعال‌سازی هایلایت سینتکس
```
